## 결정과 위험

- 새 의존성: 없음. package-lock과 application/tooling 소스는 변경하지 않았다.
- 새 결정 또는 기존 결정과의 차이: H3a exact SHA는 repository source에 쓰지 않고 GitHub Actions variable `H3A_APPROVED_RELEASE_SHA`에서 사람의 승인 후 제공한다. 이 방식은 동일 source SHA를 checkout·검증하면서 승인 SHA만 외부 설정으로 대조한다. 최신 공식 근거: [GitHub Pages custom workflows](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages), [Vite GitHub Pages deployment](https://vite.dev/guide/static-deploy.html).
